# Asset Register

Every file shipped in `public/sprites/`. Provenance, and whether a code path actually asks for it.
Licensing of third-party assets lives in [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

## Scope and how this register is checked

`public/` is copied into the build verbatim, so **every** file below ships, referenced or not.
The table is one row per file on disk; the register is reconciled against the tree — files with no
row and rows with no file both fail — by `tests/renderer.overheadBadgeAndAssets.test.ts`.

Measured 216 files / 27.43 MiB (30.43 MiB before the
resolution/compression pass), of which **122 files
(11.15 MiB) are requested by no code path**. "No code path" means the file's full
URL appears in no `src/`, `scripts/` or `tests/` file; it is not a claim that the art is worthless —
several entries are rollback copies or regeneration sources the project keeps on purpose, and each
one says so. Nothing here has been deleted: removing art needs the owner's decision.

### Resolution rule for resized art

A sprite may only be downscaled to the largest box the renderer can draw it in — that box, not the
art's own detail, bounds the resolution the player can see. The bound is the drawn box at
`CAMERA_ZOOM_MAX` (8×) multiplied by a 2× display, and the target keeps **2× headroom** over it so
the canvas filter never has to invent detail. Resizes resample the alpha edge correctly (edge colour
bled across transparency, RGB and alpha resampled apart): a straight-alpha resize blends whatever
sits behind alpha 0 into the silhouette, which darkened the child sprites' outline by up to **34
levels of 255** when the first pass did it that way.

### Outside this tree

`public/logo.png` — the only shipped asset outside `public/sprites/`. Largest use is the 128 CSS px
loading splash (`App.tsx`), so the bound is 256 device px at 2×; the favicon and
`apple-touch-icon` need 180 px. Resized from 1024×1024 to **512×512** (2× the bound), 1 568 KiB →
**287 KiB**, and the drawn result at 256 px differs from the original by at most 13.6 levels of 255
(mean 0.20).

## Generated-art rule

Any new sprite must be **either** procedurally generated (add a `scripts/generate-*.mjs`) **or**
authored in-repo and registered here in the same change. No third-party sprite without a row in
`THIRD_PARTY_NOTICES.md`.

the delivered sheets; that is recorded rather than interpreted. Confirm these before any external
