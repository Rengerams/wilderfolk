# Design: Wilderfolk v0.5.1 Roadmap

**Status:** Approved · **Date:** 2026-07-30  

**Version target:** `0.5.1`  
**Launch target:** **End of August 2026**  
**Prerequisite:** v0.5.0 shipped (`GAME_VERSION = 0.5.0`)

---

## 1. Purpose

**v0.5.1** is a **medium** (~3–4 week) patch after the 0.5.0 “valley scales” milestone. It is **not** 0.6.

**Player one-liner:**  
*The valley feels truer and clearer — what you see matches how it lives.*

### Jobs of the release

1. **Playtest fixes** — repair what real 0.5.0 sessions uncover.  
2. **Simulation refinement** — fairness and readability (ecology, raids, daily life).  
3. **Looks / presentation** — clearer map and moment cues (not a full art reboot).

### Success criteria (ship when all true)

| Goal | Meaning |
|------|---------|
| **Play** | A normal play session can finish without a known P0 blocker (moon, housing, forge, raid, Nature). |
| **Truth** | At least one sim-truth improvement players can feel (e.g. raid gold fairness, ecology readability). |
| **Looks** | At least one presentation improvement players can see (e.g. scarcity/strained cues, map/march polish). |
| **Ship** | `GAME_VERSION` / package → `0.5.1`; public ROADMAP + CHANGELOG + in-game roadmap updated. |

**Not a ship gate:** multi-year headless PASS, full Vitest expansion, or “every open problem closed.”

## 3. Three public tracks

Player language only on public surfaces.

| Track | Public theme | In scope for 0.5.1 |
|-------|--------------|--------------------|
| **Play** | *Smoother sessions* | Bugs and friction from real play (0.5.0 regressions + new findings) |
| **Truth** | *The valley makes sense* | Sim fairness & readability — raid spoils/gold (e.g. EK-D5), ecology cues so strain isn’t pure “RNG”, daily life that matches the clock |
| **Looks** | *The frontier reads on the map* | Presentation: scarcity/strained signals, clearer hunt/raid feedback, light map polish |

### Secondary (not advertised as the theme)

Engineering that supports the tracks only if free after P0: e.g. less hitch with many tabs open (`App.tsx` extract), scan cleanup, particle pooling. Ship if they land; do not block 0.5.1 on them.

### Seed candidates (not a mandatory checklist)

These are **examples** for implementers; playtest may replace them.

| Track | Examples |
|-------|----------|
| Play | Whatever playtest files; no reopening closed EK without repro |
| Truth | Cap/outgoing raid success gold; ecology readability (Nature + hunter cues already started); church/moon feel if still confusing |
| Looks | Stronger Strained visual/dialogue cues; outgoing counter-raid march line / militia sprites; light landscape polish if cheap |

---

## 4. Explicitly out of scope for 0.5.1

| Out | Why |
|-----|-----|
| Real-time map battles | Design non-goal (abstract raids) |
| Multiplayer, fog of war | Too large |
| Multi-slot save-to-file | Feature product, not patch |
| Full landscape art reboot | Defer (research exists; not medium scope) |
| Multi-year headless PASS as ship gate | Harness ≠ play; 0.5 already rejected this |
| New major systems (full quest chain, deep rep arc) | 0.6-class unless a **tiny** seed fits free capacity |

## 5. Calendar & version mechanics

| | |
|--|--|
| **Version string** | `0.5.1` |
| **Launch** | **End of August 2026** |

| **Intro / tagline** | Keep 0.5.0 tagline unless a short 0.5.1 badge line is wanted at ship (“Clearer valley” optional — not required) |

### Suggested work order

1. **Playtest triage** — log bugs, rank P0.  
2. **Play P0 fixes** in parallel with one Truth + one Looks item.  
3. **Buffer week** — only ship blockers + polish.  
4. **Ship** — version, docs, public/in-game roadmap.

## 7. Risks

| Risk | Mitigation |
|------|------------|
| Playtest finds more than 3–4 weeks | Ship with Play P0 + minimum Truth + Looks; rest → 0.5.2 |
| Scope creep into “new features” | Guard with out-of-scope table; one feature seed only if free |
| Public overpromise | Use themes, not feature laundry lists, until ship |
| Confusing 0.5.1 with 0.6 | Keep medium size and end-Aug date explicit |
