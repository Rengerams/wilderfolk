# Positioning Guardrails

The north star for every feature decision. If a proposed feature fights these,
it doesn't belong in Wilderfolk — or needs to be rethought so it serves them.

## Identity

> **Wilderfolk is a cozy frontier eco-sim about people living inside a food chain.**

Three pillars — every feature should serve at least one:
1. **The living valley** — ecology is central, not a resource skin. Grass → prey → predators → people, one loop.
2. **The people and their drama** — families, friendships, feuds, elections, generations, memory.
3. **The frontier you share** — rivals, visitors, trade, weather, raids as *risk*, not a separate game.

## Hard guardrails

| # | Guardrail | Why |
|---|---|---|
| 1 | **No PvP / no combat-as-a-game.** Raids are *preparation tests* — housing, staffing, gear, relationships, ecology all feed defense. No separate battle minigame. | Combat is preparation-focused by design; a tactical layer would split the sim's soul. |
| 2 | **No win/lose chapters.** Story moments (Valley Chronicle) *shift the world and unlock content* — they never say "you lost" or end the run. | Victory paths were removed for this reason; the sandbox keeps living. |
| 3 | **Ecology stays honest.** "Don't kill all the wolves" is the hook — hunting has consequences; preserves and quotas are real tools; the player must be able to *see* the loop (charts, species counts). | The food chain is the identity; turning it decorative kills the game. |
| 4 | **Onboard before adding systems.** New-player clarity (first-spring guide, placement feedback, one primary prompt) outranks any new content pillar. | The external review's P0: a promising game that feels broken in the first five minutes loses everyone. |
| 5 | **Settlers are people, not pawns.** Drama (affairs, feuds, gossip, elections) is generated by systems on a calendar, never scripted flavor text. | The people pillar is systemic — that's what makes it deep. |
| 6 | **Save policy: exact-version only** in beta — but documentation must always state the current policy. | Mixed save messages destroy trust. |
| 7 | **No new dependencies without a fight.** Canvas 2D + the existing stack is the home; a new package must save real work, not just look cleaner. | PixiJS was built then removed; the repo's precedent is "do it in-house." |
| 8 | **Art is self-generated.** New sprites are procedural (a `generate-*.mjs` script) or hand-authored in-repo and registered in `docs/ASSET_REGISTER.md`; third-party assets go through `docs/THIRD_PARTY_NOTICES.md`. | Distribution safety + regenerability. |

## Tone

Cozy, warm, alive — never grimdark, never ironic. The frontier is hard but fair; the valley rewards
attention and punishes neglect gently enough that you can always recover. Don't kill all the wolves.
